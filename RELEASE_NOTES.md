# Matcha 1.5.9

**[⬇ Download Matcha for Mac](https://github.com/jakeantelis/Matcha/releases/download/v1.5.9/Matcha.dmg)** · macOS 11 or newer · Apple silicon and Intel

Updates are now signed, and you choose whether they happen on their own.

- Matcha now updates through Sparkle. It asks once whether to check for updates automatically, then checks about once a day and shows what is new before installing. You can still choose Check for Updates at any time.
- Every update is signed with Matcha's own key, and Matcha checks the signature before installing it. Checks go to GitHub and send no personal information.
- A running session carries on across an update, as before.

_Install and uninstall instructions live in the [README](https://github.com/jakeantelis/Matcha#install)._
